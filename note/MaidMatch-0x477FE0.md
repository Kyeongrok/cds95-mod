# 여급 성격과 궁합 — 표 셋 · 0x477FE0 / 0x47CB70

여급마다 **성격**이 하나 있고, 주인공에게는 그 성격 8종에 대한 **선호(0~2)** 가 있다.
말을 걸었을 때 친밀도가 얼마나 오르는지가 이 선호로 갈린다 — 그것이 "궁합"이다.

## 여급 표에 있는 두 자리

여급 표(`.rdata 0x517AF8`, 40바이트 x 127) 중 오래 미상으로 두었던 둘:

| 오프셋 | 뜻 |
|---|---|
| +0x14 | **운명의 반려자 얼굴코드**(0~30) |
| +0x18 | **성격**(0~7) |

`cds_save_editor` 의 `barmaid_database` 와 127명 전원 대조해 하나도 어긋나지 않았다
(`personality_ids` = +0x18, `fortune_face_code` = +0x14).

성격 이름은 게임이 `0x4A2F10` 에서 번호로 고르는 문자열 그대로다:

```
0 당당한   1 강인한   2 의지가 강한   3 용감한
4 친절한   5 로맨틱한  6 섬세한       7 견실한
```

여급이 하는 말도 이 값으로 갈린다 — `0x4A3130` 이 표 +0x18 을 읽어 8갈래
점프 테이블(`0x4A36AC`)로 대사를 고른다.

## 주인공의 선호 — `0x477FE0` + `0x47CB70`

```c
// 0x477FE0 — 여급·후원자도 같이 쓰는 공통 계산
void Prefs(this, int out[8])
{
    z = vtable+0x28(this);                  // 성좌
    b = vtable+0x1C(this);                  // 혈액형
    for (i = 0; i < 8; i++)
        out[i] = zodTable[z][i] + bloodTable[b][i];
    for (i = 0; i < 8; i++) out[i] = clamp(out[i], 0, 2);   // 0x49E540
}

// 0x47CB70 — 주인공만 한 단계 더 있다
void PlayerPrefs(this, int out[8])
{
    Prefs(this, out);
    f   = vtable+0x08(this);                // 표시 얼굴코드 (36세부터 +16 — 0x47CAF0)
    row = faceTable + f * 32;
    out[ row[6] ] += row[7];                // (성격번호, 보정) 한 쌍
    for (i = 0; i < 8; i++) out[i] = clamp(out[i], 0, 2);
}
```

표 셋 (전부 EXE 에 구워져 있다):

| 표 | VA | RVA | 크기 |
|---|---|---|---|
| 성좌 → 성격 선호 | `0x568578` | `0x168578` | 12 x 8 int |
| 혈액형 → 보정 | `0x5686F8` | `0x1686F8` | 4 x 8 int (성좌표 바로 뒤) |
| 얼굴 → 성격 하나 보정 | `0x51ACA0` | `0x11ACA0` | 32줄 x 32바이트, +0x18 성격번호 · +0x1C 보정 |

성좌표(행 = 성좌 0 양자리 … 11 물고기자리, 열 = 성격 0~7):

```
             당당 강인 의지 용감 친절 로맨 섬세 견실
양자리        2   1   0   2   1   1   1   0
황소자리      1   0   2   1   1   0   1   2
쌍둥이자리    1   0   0   1   1   2   2   0
게자리        0   1   1   0   2   1   1   2
사자자리      2   1   1   2   1   1   0   0
처녀자리      1   2   0   0   1   1   2   2
천칭자리      2   2   1   1   0   1   1   1
전갈자리      1   1   2   1   2   0   2   0
궁수자리      1   2   0   1   2   2   1   2
염소자리      2   1   2   1   1   0   1   1
물병자리      1   2   0   1   1   1   0   1
물고기자리    0   0   1   1   2   1   1   1
```

혈액형표는 ±1 한 칸씩만 건드린다: A(섬세 +1, 견실 -1) · B(강인 +1, 섬세 -1) ·
O(당당 +1, 친절 -1) · AB(의지 -1, 로맨틱 +1).

성좌는 생월·생일에서 나온다 — `0x42E620` 이 `월*100 + 일` 을 만들고 3/21 이전이면
1200 을 더한 뒤 경계표 `0x547260`(12 x [시작, 끝])에서 찾는다. 0 = 양자리(3/21~4/20).

## 궁합이 갈리는 자리 — `0x00465C61`

여급과 이야기할 때다.

```c
p = 여급표[row] +0x18;              // 여급 성격
플레이어.vtable+0x24(&pref);        // 위 PlayerPrefs
if (pref[p] == 2) {                 // 궁합이 좋다
    말한다(문자열 0x55B588);
    친밀도 += 5 + rand(15);
} else {
    말한다(문자열 0x55B5B8);
    친밀도 += 2 + rand(10);
}
if (친밀도 > 60) 친밀도 = 60;       // 이 자리에서는 60 이 상한
```

그래서 **선호 2 = 궁합 좋음**이고, 그 외(1·0)는 게임 안에서 서로 다르지 않다.
창에는 그래도 ◎ / ○ / △ 로 갈라 적는다 — 얼굴이나 나이가 바뀌면 1 이 2 가 되기도 해서
"조금만 더 가면 맞는 사이"를 보이는 편이 낫다.

## 운명의 반려자 — `0x0040A680`

점술 화면이다. 여급 127칸을 훑어 `표+0x14 == 주인공의 표시 얼굴코드` 인 여급을 찾고,
그 여급이 지금 있는 도시 이름을 일러 준다(문자열 `0x538B28`). 표시 얼굴이므로
**36세를 넘기면 짝이 바뀐다** — 얼굴코드에 16 이 더해지기 때문이다
(`cds95-player-portrait-slot16` 에 적어 둔 그 규칙).
