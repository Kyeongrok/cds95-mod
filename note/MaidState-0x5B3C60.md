# 여급의 "살아 있는" 상태 — 배열 0x5B3C60 / 친밀도 +0x20

여급 127명은 자리가 둘이다.

- **표**(`.rdata` `0x517AF8`, 40바이트 x 127) — 이름·얼굴·나이·혈액형·언어·시작 도시.
  게임을 켜면 늘 그 자리에 있고 세이브와 무관하다. (`maids.c`)
- **객체 배열**(`.data` `0x5B3C60`, **60바이트 x 127**) — 친밀도·지금 도시처럼
  판마다 달라지는 것. **세이브에 그대로 들어간다.** 이 글은 이쪽이다.

## 배열

`0x00479510` 이 `0x5B3C60` 부터 `0x3C` 씩 127칸을 돌며 `0x479530` 을 불러
vtable `0x518ED0` 을 꽂는다. 끝은 `0x5B5A24`(= 0x5B3C60 + 60*127).

```
00479510  mov  edi, 0x5b3c60
00479515  mov  esi, 0x7e            ; 126 -> 127칸
0047951c  mov  ecx, edi
0047951e  add  edi, 0x3c
00479521  call 0x479530             ; *(void**)ecx = 0x518ed0
00479526  dec  esi
00479527  jns  0x47951c
```

칸 -> 행 번호는 `0x479740`(`(this - 0x5B3C60) / 0x3C`), 행 번호 -> 칸은
`0x477B52`. 인물 종류를 한데 다루는 `ObjFromId`(`0x477B10`)에서 **여급은 종류 2** 다
(id = `종류 << 12 | 행`, 점프 테이블 `0x477BD4`).

## 칸 배치

| 오프셋 | 뜻 | 처음 값 |
|---|---|---|
| +0x00 | vtable (`0x518ED0`) | — |
| +0x04 | 종류(2 = 여급) | 2 |
| +0x20 | **친밀도 0~100** | 0 |
| +0x24 | **지금 있는 도시** | 표 +0x24(시작 도시) |
| +0x28 | 미상 | 1 |
| +0x2C | 미상 | 0 |
| +0x30 | 미상 | 1 |
| +0x34 | 미상 | 0 |
| +0x38 | 남은 일수(카운트다운) | -1 |

생성자 `0x4795F0` 이 +0x24 에 **표 +0x24**(`0x517B1C + row*40`)를 옮겨 담고
나머지를 위 값으로 채운다. 새 판을 시작할 때는 `0x461E6C` 가 127칸을 다시 훑어
`+0x28=1 +0x20=0 +0x30=1 +0x34=0` 으로 되돌린다.

- **친밀도**: `0x478530` 이 `+0x20` 을 **0~100 으로 잘라(clamp) 더한다**(`0x49E560`).
  `0x4A4977` 이 그 값에 `rand()%50` 을 더해 판정에 쓴다 — 여급에게 뭔가를 청할 때다.
  같은 필드를 후원자도 쓴다(부모 클래스가 같다. `patrons.c` 의 친밀도 `0x629AF8 +0x00`).
- **+0x38**: `0x479790` 이 하루가 갈 때마다 인자만큼 빼고 0 아래로 내려가면 -1 로 돌린다
  (`0x44B1E7` 이 127칸에 대해 1 씩 부른다). "며칠 뒤" 짜리 상태로 보인다.
- **+0x24 도시**: `0x4A1880` 이 그 도시에 세울 여급 후보를 모을 때 vtable+0x2C(= `+0x24` getter)
  로 비교한다. 여급은 판이 도는 동안 도시를 옮겨 다닌다.

## 세이브에 남는다

여급 127칸을 훑는 직렬화 루프가 넷 있다(세이브 쓰기·읽기·크기 계산 …):
`0x478626` / `0x478C82` / `0x478F86` / `0x4792CC` — 전부 `0x5B3C60` 에서 `0x5B5A24` 까지
`0x3C` 씩이다. 칸마다 부르는 것은

- 쓰기 `0x4796B0` — vtable+0x2C(`+0x24`), `+0x30`, vtable+0x34(`+0x28`), `+0x2C`, `+0x38`, `+0x34`
- 읽기 `0x479630` — 같은 순서로 되읽어 그 자리에 넣는다
- 친밀도 `+0x20` 은 부모 클래스가 맡는다: 쓰기 `0x478500`, 읽기 `0x4784D0`

그래서 **친밀도와 지금 도시를 포함해 +0x20 ~ +0x38 이 세이브에 들어간다.**
세이브를 불러오면 그대로 살아나고, 새 판을 시작하면 `0x461E6C` 가 0 으로 되돌린다.

## 쓰는 곳

`CharacterUtilKR` 의 **[여급]** 탭 — 필터바 **[전체] / [만난 여급]**(친밀도 > 0),
칸 머리글의 **친밀 N**, 시작 도시와 다르면 **지금 <도시>** 한 줄
(`maids.c` 의 `Maid_LiveReady` / `Maid_Intimacy` / `Maid_LiveCity` / `Maid_Met`).

## 확인하는 법

`plugins-src/tools/dump-maid-state.ps1` 로 127칸을 그대로 본다.

```
.\dump-maid-state.ps1                  # 초기값과 다른 칸만
.\dump-maid-state.ps1 -Save before.csv # 스냅샷
  ... 게임에서 여급에게 말을 걸고 ...
.\dump-maid-state.ps1 -Diff before.csv # 어느 필드가 움직였는지
```

`+0x28`·`+0x2C`·`+0x34` 가 무엇인지는 아직 모른다. CE 표(`ce/CDS_95.CT`)는 `+0x28` 을
"만남유무"라고 적어 두었는데 처음 값이 1 이라 그대로 믿기 어렵다 — 말을 건 전후로
`-Diff` 를 떠 보면 갈린다.
