# 도시 진입 물음 — 0x48D810 (근접 검사) 와 그 뒷부분

배(또는 말)가 도시 옆을 지날 때 뜨는 **"[리스본]의 항구로 들어가겠습니까?"** 를
어디서 어떻게 띄우는지 정리한다. 주소는 전부 데스크톱의 한국어판
`대항해시대3\CDS_95.EXE` (ImageBase 0x400000) 정적 분석으로 확정했다.

## 어떻게 찾았나

문구로는 못 찾았다 — `항구로` 로 훑으면 안 나온다. 실제 문구가
`[%s]의 %s%s 들어가겠습니까?` 라 `항구` 와 `로` 가 따로 있기 때문이다.
그래서 **아는 주소를 참조하는 코드**부터 뒤졌다:

- `0x005B6154` (현재 입항 도시 ID) 를 **쓰는** 자리 → `0x48B51E`, `0x48B5EC`, `0x48DC00`
- 그 바로 앞이 전부 `call 0x49E3E0` + `cmp eax, 2` 였다 → 물음 함수를 잡았다

한국어 문자열은 EXE 안에 **CP949 그대로** 들어 있다(커스텀 인코딩이 아니다).
`0x570868 "도시"`, `0x570870 "항구"`, `0x5708B0 "[%s]의 %s%s 들어가겠습니까?"`.

## 함수 · 자리

| 주소 | 규약 | 하는 일 |
|---|---|---|
| `0x0049E3E0` | `__cdecl int(int 갈래, int, const char* 서식, ...)` | 대화상자. 갈래 2 = YES/NO, **YES 면 2**. 갈래 0 = 알림만 |
| `0x004281B0` | `__cdecl const char*(const char* 말, int 갈래)` | 조사 고르기. 갈래 `0xA` 는 "로 / 으로" (한국어판이 넣은 함수) |
| `0x00429950` | `__cdecl void*(int 도시)` | 도시 구조체 = `0x5863A8 + 도시*92` (`-1` 이면 0) |
| `0x00429970` | `__cdecl` | 위의 껍데기 |
| `0x00429D20` | `__thiscall int(도시구조체)` | `(this - 0x5863A8) / 92` = 도시 번호 |
| `0x00429980` | `__thiscall void*(도시구조체)` | `0x4D14B0 + 도시*136` 레코드. **`[레코드+0]` 이 도시명(CP949)** |
| `0x00473DC0` | `__thiscall void*(this=0x5B3928, int i)` | 파티원 i (없으면 0). `ret 4` |
| `0x0044CA70` | `__thiscall void(파티원, int 도시)` | 그 사람의 현재 도시(`+0x60`). `ret 4` |
| `0x004255A0` | `__cdecl int(x, y)` | 그 칸의 도시 번호(없으면 -1) |

전역:

| 주소 | 뜻 |
|---|---|
| `0x005B6154` | 지금 있는 도시. **-1 이면 항해 중** |
| `0x005B6384` | "방금 들어왔다" — 도시 화면(`0x491F00`)이 보고 `0x492CAF` 에서 지운다 |
| `0x005B6158` | 진입 갈래 (육상이면 0xA, 배면 0) |
| `0x005B61B4` | **0 이면 배, 아니면 육상(말)** |
| `0x005B3950` | 60 이상이면 문구가 "모두 지쳐 있으니 …"(`0x570878`) 로 바뀐다 |
| `0x005B63B0` / `0x005B63B4` | 함대 경도 / 위도. **칸 좌표 = 값/16** |
| `0x005A4D40`, `0x005B39FC` | 들어갈 때 같이 0 으로 되돌린다 |

## 흐름

`0x48D810` (`__thiscall`, this = 항해 화면 객체) 이 한 몸으로 두 가지를 한다.
부르는 곳은 딱 하나 — `0x48EF4D`, 항해 루프 `0x48E980` 안이고 `[0x5A4D18] & 8` 일 때만.

1. `0x48D867~0x48DA19` — 함대 둘레를 훑어 **발견물** 처리
2. `0x48DA19~0x48DB08` — 함대 칸 둘레(-3~+1)를 훑어 **들어갈 수 있는 도시**를 고른다
   판정(`0x48DAC7`): `[도시+4] & 1` 서 있고 `& 4` 는 꺼져 있어야 하며,
   배면 `[도시+0x1C] & 1`(항구 비트), 육상이면 `[도시+0x1D] & 4`
3. `0x48DB08~0x48DC55` — **물어보고 들여보낸다**
   - `[this+0xF4]` 가 지난번에 물어본 도시다. 같으면 다시 안 묻는다(빗장)
   - 문구를 짜서 `0x49E3E0(2, 0, 서식, 이름, 항구/도시, 조사, 조사)`
   - `== 2` 면 아래를 실행하고 돌아간다. 도시 화면 전환은 게임이 알아서 한다

```
*(int*)0x5B6384 = 1;
*(int*)0x5B6154 = 도시;
if (*(int*)0x5B61B4) *(int*)0x5B6158 = 0xA;
else { for (i=0;i<8;i++) { m = 0x473DC0(0x5B3928, i); if (m) 0x44CA70(m, 도시); }
       *(int*)0x5B6158 = 0; }
*(int*)0x5A4D40 = 0;
*(short*)0x5B39FC = 0;
```

**이 마지막 대목은 `this` 를 쓰지 않는다** — 전역과 도시 번호만 있으면 된다.
TradeUtilKR 의 "시세 일람 두 번 누르기" 가 이것을 그대로 옮겨 썼다
(`plugins-src/TradeUtilKR/src/trade.c` 의 "도시 진입" 절).

## 다른 진입 자리

`0x48B4A9` — 커맨드 메뉴(`기능` / `커맨드`)에서 가까운 도시를 골라 들어가는 길.
문구가 `0x56FA20 "[%s]에 들어갑니다"` 로 다르고, YES 뒤 처리는 위와 똑같다.

`0x48B5C0` — **출항**. `0x5B63B0/B4` 를 `0x5B63B8/BC`(정박 전 좌표)로 되돌리고
`0x5B6154 = -1` 로 놓는다. → **도시 안에서 워프해 봐야 출항할 때 되돌려진다.**
워프도 진입도 항해 중에 해야 뜻대로 된다.

## 되짚는 법

`plugins-src/tools` 에 넣을 만큼 다듬지는 않았지만, 이 조사는 capstone 으로 했다:

```python
# VA -> 파일 오프셋은 PE 섹션 표로 계산 (.text VA=0x401000 RawPtr=0x400)
from capstone import *
md = Cs(CS_ARCH_X86, CS_MODE_32)
```

문자열은 `codecs` 로 CP949 디코드하면 그대로 읽힌다.
