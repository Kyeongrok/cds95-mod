# TradeUtilKR 투자 기능 추가 조사

원본 문서 `3.TradeUtil.md` + 현재 KR 플러그인 코드(`plugins-src/TradeUtilKR/src/trade.c`) 대조 정리.

## 게임 메커니즘 (원본 TradeUtil 기준)

### 투자하면 바로 성장하나? → 아니오
- 투자할 때마다 규모가 오르는 게 아니라 **누적 투자액**이 단계별 임계치를 넘을 때 규모 +1.
- 기본 임계치 = `규모 × 규모 × 10만` 금화 (INI로 조정).
- 각 단계는 **누적이 아니라 그 단계에 필요한 금액**.
  - 원래 규모 4인 리스본 → 규모 5: 250만.
  - 원래 규모 1인 오포르투 → 규모 5: 40만+90만+160만+250만 = 540만.
- 규모 자체는 세이브에 저장하지 않고, **EXE 원본값 + 누적 투자액**으로 로드할 때마다 재계산해서 도시 구조체에 덮어씀.
- 현재 상한 규모 6 (7 이상 미검증).

### 성장하면 교역품이 추가되나? → 새 품목 추가 아님
- 규모가 오르면 **그 도시 특산품의 생산량**이 오름.
- 생산량 8단계: 20 / 50 / 100 / 200 / 350 / 500 / 700 / 1000. 현재 규모+2단계까지만 상향.
- **즉시 재고가 늘지 않고**, 월이 바뀌는 시점에 새 생산량으로 재고가 만들어짐.
- 이미 생산량이 높은 도시(예: 규모1인데 이미 500)면 안 오를 수 있음. 기본 생산량보다 낮아지지도 않음.

**전체 흐름:** 투자 누적 → 임계 돌파 시 규모+1 → 특산품 생산량 상향 → 다음 달 재고 반영.

## 현재 KR 플러그인 구현 상태

- 도시 목록·시세·규모 읽기·교역품 관리까지 구현됨. **투자는 미구현.**
- 메뉴: `교역`(ID_TRADE_SISE 0xB101), `교역품`(ID_TRADE_GOODS 0xB102).

### 이미 확보된 것 (재사용 가능)
- 도시 구조체 베이스 `SISE_BASE = 0x005863B4`, stride 92.
- 필드 오프셋: 규모 −4(i32, 읽기/쓰기 가능), 시세 0, 건물수치 +0x10(u16 비트필드), 시장아이템1~8 +20~+48(i32×8).
- 건물 비트: 항구0 / 교역소1 / 조선소6 / 조합7 / 도서관8.
- 메뉴 후킹(서브클래싱) 인프라, 다이얼로그 UI 틀.

## 단계별 진행 제안

- **1단계 (검증용, 저장 없이):** 현재도시+소지금 주소만 찾아서, 투자 시 규모 필드(−4)에 즉시 +1 써보고 시세/목록에 반영되는지 확인. 게임이 규모 변화를 받아들이는지부터 검증.
- **2단계:** 생산량 오프셋 찾아 규모↔생산량 연동, 월 바뀔 때 증산 확인.
- **3단계:** EXTRADATA 누적 투자액 저장 + 로드 재계산.

우선순위: 현재 체류 도시 / 소지금 / 생산량 오프셋을 찾는 CE 세션부터.
