# DialogUtilKR — 게임 문구를 파일로 갈아 끼운다

게임의 한국어 문구는 `CDS_95.EXE` 안에 **CP949 그대로** 들어 있다. 이 플러그인은 그 문구를
`CDS95Util\dialogs\*.json` 에 적어 둔 대로 **메모리에서** 바꿔 준다. EXE 파일은 건드리지
않으므로 게임을 끄면 원래대로 돌아간다.

## 쓰는 법

`CDS95Util\dialogs\` 에 `.json` 을 아무 이름으로 넣는다(**UTF-8 로 저장**).

```json
[
  {
    "Note": "술집 인사 1",
    "Find": "여어! 당신, 음...누구였더라? 자, 이쪽으로 오게나.",
    "Text": "여어! 자네 낯이 익은데. 자, 이쪽으로 오게나."
  },
  {
    "Find": "쳇, 재미없군.",
    "Text": "쳇, 시시한 사람이군. 술맛 떨어지는군."
  }
]
```

게임을 켜면 바로 적용된다. 켠 채로 고쳤다면 **파일 > 모드 > 대사** 창에서 [다시 읽기].

| 키 | 뜻 |
|---|---|
| `Find` (또는 `원문`) | 바꿀 원문. EXE 의 데이터 구역에서 이 문구를 찾는다. **글자 하나까지 똑같아야 한다** |
| `Text` (또는 `대사`) | 새 문구 |
| `Note` (또는 `설명`) | 사람이 알아보려고 적는 메모. 게임은 안 쓴다 |
| `Address` (또는 `주소`) | 원문 대신 **파일오프셋**으로 자리를 직접 준다 (`"0x147A48"`) |
| `All` (또는 `전부`) | 같은 원문이 여러 자리에 있을 때 전부 바꿀까. 기본 `true` |
| `Enabled` (또는 `켬`) | 이 줄을 쓸까. 기본 `true` |

모드로 나눠 주고 싶으면 `CDS95Util\mods\<만든이>\dialogs\*.json` 에 넣어도 된다.

## 길이 — 넘어도 된다

문구마다 다음 문구까지의 폭이 정해져 있다. 새 글이 그 폭에 들면 그 자리에 그대로 쓰고,
넘으면 플러그인이 잡아 둔 메모리에 새 글을 두고 **그 문구를 가리키던 포인터를 전부 새 주소로
돌린다**. 포인터는 두 곳에서 찾는다.

- 데이터 표 — 4바이트 정렬 자리의 값이 그 문구 주소인 곳
- 코드 — `push imm32` / `mov r32, imm32` / `mov r/m32, imm32` 의 imm32 자리.
  명령 길이를 세어 확인하므로, 우연히 같은 4바이트가 코드에 박혀 있어도 잘못 고치지 않는다

가리키는 곳을 하나도 못 찾으면 그 줄은 적용하지 않고 창에 까닭을 적는다(원문 자리는 그대로 둔다).

## 원문은 어떻게 아나

`plugins-src/tools/dump-dialogs.py` 로 EXE 에서 뽑는다.

```
python plugins-src/tools/dump-dialogs.py --exe "…\대항해시대3\CDS_95.EXE" --find 술집
python plugins-src/tools/dump-dialogs.py --exe "…\CDS_95.EXE" --range 0x54A200 0x54B0B0 --json
```

`--json` 을 주면 `Find`/`Text` 가 채워진 채로 나오므로 `Text` 만 고쳐 `dialogs\` 에 넣으면 된다.

## 알아 둘 것

- **JSON 은 UTF-8 로 저장한다.** 플러그인이 CP949 로 바꿔 넣는다
- CP949 에 없는 글자(예: 한자·특수기호 일부)는 `?` 로 들어간다
- 같은 문구를 PatchUtilKR 의 글자 패치로도 바꿔 뒀다면, 먼저 바뀐 쪽 때문에 원문 검색이
  실패한다. 한 문구는 한 군데서만 손대는 게 좋다
- 창의 "상태" 칸에 몇 곳을 고쳤는지, 재배치를 썼는지, 왜 실패했는지가 나온다.
  자세한 것은 DebugView 로 `[DialogUtilKR]` 로그를 보면 된다

## 안에서 무슨 일이 일어나나

`src/dialog.c` 한 파일이다.

| 함수 | 하는 일 |
|---|---|
| `FindAll` | `.data`/`.rdata` 에서 널로 끝나는 문구를 찾는다. 앞 바이트가 0 인 자리만 잡아 한복판을 물지 않는다 |
| `SlotCap` | 그 자리에 쓸 수 있는 바이트 수 = 원문 길이 + 뒤에 이어지는 0 개수 |
| `ImmHere` | 코드의 imm32 가 정확히 그 자리인지 명령 길이를 세어 본다 |
| `RewritePointers` | 옛 주소를 가리키던 자리를 전부 새 주소로 돌린다 |
| `Remember` / `RevertAll` | 고치기 전 바이트를 적어 둔다. [다시 읽기] 는 되돌린 뒤 다시 적용한다 |

분석 배경은 옵시디안 `Project/cds95/분석/14.분석-술집 화면과 대사.md` 에 있다.
