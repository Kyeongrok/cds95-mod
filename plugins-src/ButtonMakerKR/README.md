# ButtonMakerKR — 게임과 똑같은 메뉴 띠를 글자만 바꿔 만든다

게임의 메뉴 타이틀·버튼은 `MISC.CDS` 안의 조각 몇 개를 이어 붙이고 그 위에 비트맵 글꼴로
글자를 찍은 것이다. 이 플러그인은 그 짓는 법을 그대로 따라 해서, **종류를 고르고 글자를
치면 같은 띠 그림을 만들어 준다.** PNG 로 저장하거나 클립보드로 복사할 수 있다.

게임 화면은 건드리지 않는다 — 파일도 읽기만 한다.

## 쓰는 법

게임에서 **파일 > 모드 > 버튼 만들기**.

| 칸 | 뜻 |
|---|---|
| 종류 | `진홍`(타이틀) · `베이지`(버튼) · `회녹색`(다른 상태) |
| 글자 | 찍을 글자. 완성형 한글과 ASCII 를 쓴다 |
| 폭 자동 | 켜면 글자가 들어갈 만큼만, 끄면 **칸** 수대로 |
| 칸 | 가운데 조각(8픽셀)을 몇 번 되풀이할지. 띠 폭 = 16 + 8 x 칸 + 16 |
| 글자색 | 게임 공용 색표의 색인 여섯 가지. 화면에서 되짚은 값이 기본이다 |
| 그림자 | 글자 오른쪽 아래로 한 점 |
| 미리보기 | 1~4배 |

띠 높이는 늘 **24픽셀**이다(게임이 그렇게 그린다).

> **콤보 상자를 쓰지 않는다.** 처음에는 종류·글자색·그림자·배율을 드롭다운으로 뒀는데,
> 게임 안에서 목록을 고르면 게임이 그 자리에서 죽었다(창만 따로 띄워 두들겼을 때는 멀쩡했다).
> 콤보는 목록을 펼 때 게임 창 위에 별도 팝업을 띄우고 제 모달 루프를 돌린다 — 그동안
> 게임의 메시지 루프가 멈춰서 DirectDraw 쪽이 버티지 못하는 것으로 보인다.
> 그래서 전부 **라디오 버튼**으로 바꿨다(그냥 자식 창이라 팝업도 모달 루프도 없다).
> 띠를 짓고 그리는 자리는 `__try/__except` 로 감싸 두었으니, 혹시 터져도 게임은 살고
> DebugView 에 `[ButtonMakerKR] !! …` 로 자리가 남는다.

## 어디서 오는 그림인가

### 껍데기 — `MISC.CDS` 파트 4 (2,880바이트)

한 벌 960바이트씩 세 벌이고, 한 벌 안은 조각 셋이다. 조각마다 제 폭으로 위에서 아래로
담긴 8bpp 색인이다.

| 자리 | 크기 | 조각 |
|---|---|---|
| +0 | 16 x 24 (384바이트) | 왼끝 |
| +384 | 8 x 24 (192바이트) | 가운데 — 폭만큼 되풀이 |
| +576 | 16 x 24 (384바이트) | 오른끝 |

| 벌 | 쓰임 |
|---|---|
| 0 | 진홍 장식 — 메뉴 타이틀 |
| 1 | 베이지 — 보통 버튼 |
| 2 | 회녹색 — 다른 상태 버튼 |

게임도 똑같이 짓는다.

| 것 | 주소 |
|---|---|
| 파트 4 를 읽어 두는 자리 | `0x00463590` → 객체 `0x005AA3B8` 의 `+0x14` |
| 조각 꺼내기 | `0x00463710(벌, 조각)` |
| 조각 시작 열 표 | `0x00552898` = `{0, 16, 24}` (열 하나가 24바이트) |
| 띠 짓기 | `0x0041F606` — 왼끝 `0x41F61B`, 가운데 되풀이 `0x41F677`, 오른끝 `0x41F6EB` |

### 글자 — `ALL_FONT.16P` · `ANKFONT.DAT`

| 파일 | 형식 |
|---|---|
| `ALL_FONT.16P` | 30바이트 레코드 3,478개. `u16 코드`(리틀엔디언, KS X 1001 두 바이트를 빅엔디언 수로) + 28바이트 = **16폭 x 14행** 1bpp. 코드 `0xA1A1`~`0xC8FE` — 기호와 완성형 한글 2,350자, 한자 없음 |
| `ANKFONT.DAT` | 16바이트 글리프 96개. **8폭 x 16행** 1bpp, ASCII `0x20`~`0x7F` |

게임도 이 둘을 읽는다 — `0x004109C3` / `0x004109CD`
(문자열 `"C:ALL_FONT.16P"` = `0x535CCC`, `"C:ANKFONT.DAT"` = `0x535CBC`).

색은 게임 공용 색표(`game_palette.h`)를 그대로 쓴다. 화면에서 되짚어 보면 타이틀 글자는
색인 **26**, 베이지 버튼 글자는 색인 **17** 이다.

## 안에서 무슨 일이 일어나나

| 파일 | 하는 일 |
|---|---|
| `miscskin.c` | `MISC.CDS` 파트 4 를 풀어 조각 아홉 개를 잡아 둔다 |
| `gamefont.c` | 두 글꼴 파일을 읽고, 유니코드 한 글자를 CP949 로 옮겨 글리프를 찾는다 |
| `band.c` | 조각을 이어 띠를 만들고 글자를 가운데 맞춤으로 찍는다 |
| `btnwin.c` | 창·미리보기·PNG 저장·클립보드 복사, 그리고 메뉴 설치 |

자세한 것은 DebugView 로 `[ButtonMakerKR]` 로그를 보면 된다.
분석 내력은 옵시디안 `21.분석-건물 사진(MPCG.CDS)과 메뉴 껍데기(MISC.CDS)` 에 적어 뒀다.
